# 部署与 5 分钟演示

## 发布前准备

1. 将老师的原始 CSV 放入项目，运行 `python run_pipeline.py`。
2. 检查 `reports/data_quality.json` 的删除和插补情况，并确认 `training_metadata.json` 中 `demo` 为 `false`。
3. 网页默认只加载正式数据，确认三个页面正常；检查分类报告和数据/模型版本。
4. 将源代码、`requirements.txt`、`.streamlit/config.toml`、正式 `ev_model.pkl`、正式 `cleaned_ev_dataset.csv` 和 `reports/` 提交到你选择的 GitHub 仓库。不要提交 `.venv`、缓存、账号密钥或 PyCharm 临时状态。
5. 项目默认忽略原始 CSV；本机保留原始文件用于复现，公开部署使用清洗 CSV、报告和模型。演示目录与演示生成入口已移除。

## Streamlit Community Cloud

1. 登录 Streamlit Community Cloud 并连接自己的 GitHub。
2. 选择 Create app，指定仓库、分支以及入口 `app.py`。
3. Advanced settings 中选择 Python 3.12，与本机环境一致。
4. 部署完成后，用新浏览器窗口检查网址能否访问、正式数据是否加载、三页功能是否正常。
5. 将实际 GitHub 仓库网址和 `streamlit.app` 网址记录在提交材料中。

模型训练和网页加载需要一致的 scikit-learn 版本；本项目 `requirements.txt` 已锁定当前验证版本。更换版本时应重新训练模型。

GitHub 公开仓库：https://github.com/hezishen846-eng/ev-campus-assessment2 。

Streamlit Cloud 在线网址：https://ev-campus-hezishen846.streamlit.app/ 。

部署来源为该仓库的 `main` 分支，入口 `app.py`，Python 3.12。本次版本使用 2026-10-24 提供的课程 CSV，1,200 条会话，DecisionTree 模型。演示视频由作者自行录制上传，完成后再补充链接。

官方依据：[部署步骤](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)、[依赖配置](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/app-dependencies)。
